# 华语一知识群岛 · Mandarin 1 Knowledge Isles

LEM-1401 / LM-1403 Mandarin 1 (UBD Language Centre, AY 2026/27 Semester 1) 的 3D 南洋风格知识岛游戏。

- 9 座岛 = 9 个 Module（Week 1–14）
- 探索：生词、句型、常见错误，点击即可听发音
- 闯关：每岛 5 题（M9 为 10 题全学期综合），答对 3 题得 1 颗星并解锁下一岛
- 进度保存在学生自己的浏览器里
