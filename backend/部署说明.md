# 登入后台部署说明（约 10 分钟，只需要做一次）

学生用 **班级代码 + 昵称 + 4 位数字密码** 登入。进度存在 **你自己的 Google 表格** 里，老师后台网页也是从这里读取资料。

## 第 1 步：建立 Google 表格并贴上程序

1. 打开 <https://sheets.new>，建立一个新的 Google 表格，命名为「知识群岛后台」。
2. 上方菜单选 **扩展程序 → Apps Script**（英文界面是 *Extensions → Apps Script*）。
3. 把编辑器里原有的内容全部删掉，换成本文件夹里 **`Code.gs`** 的全部内容（在 GitHub 打开 `backend/Code.gs` → 点 *Raw* → 全选复制）。
4. 按 💾 **保存**。

## 第 2 步：部署成网络应用

1. 在 Apps Script 右上角按 **部署 → 新建部署**（*Deploy → New deployment*）。
2. 齿轮图标选 **网页应用**（*Web app*）。
3. 设定：
   - **执行身份 Execute as：我（你的邮箱）**
   - **谁可以访问 Who has access：任何人 Anyone**
4. 按 **部署**。第一次会要求授权：选你的账号 → 如果出现“Google 尚未验证此应用”，点 **高级 → 前往（不安全）** → **允许**。这是你自己写的程序，只能存取这一个表格。
5. 复制出现的 **网页应用网址**（以 `https://script.google.com/macros/s/` 开头、`/exec` 结尾）。

> “任何人”的意思是学生不用 Google 账号就能登入游戏。别人只拿到网址也看不到资料：学生资料要用班级代码和密码才能读写，老师资料要老师密码。

## 第 3 步：设定老师密码、建立班级代码

1. 回到 Google 表格，**重新整理页面**。上方会多出一个 **「知识群岛」** 菜单（如果没有，请等几秒后再整理一次）。
2. 依次点：
   - **1. 初始化表格**：会建立「班级 Classes」和「学生 Students」两个分页。
   - **2. 设定老师密码**：至少 8 个字符，用来进入老师后台。
   - **3. 建立班级代码**：例如 `MANDARIN1A`（3–12 个英文字母或数字）。之后也可以在老师后台建立。

## 第 4 步：把网址填进游戏

把第 2 步复制的网址发给 Claude，或者自己在 GitHub 编辑 `config.js`：

```js
window.ISLES_API = "https://script.google.com/macros/s/……/exec";
```

存档后约 1 分钟，游戏就会出现登入画面，老师后台在 `teacher.html`：
<https://taykokjun-88.github.io/mandarinknowledgeislandlevel1/teacher.html>

## 给学生的说明

1. 打开游戏 → 选 **「第一次来：注册」**。
2. **班级代码** 填老师给的代码（例如 `MANDARIN1A`）。
3. 自己取一个 **昵称**（不用真实姓名），设一个 **4 位数字密码**。
4. 以后在任何设备选 **「登入」**，输入同样的班级代码、昵称和密码，就能接着玩。
5. 在学校共用的 iPad 上玩完，请到 **「我的成绩」→ 登出**。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 学生忘记密码 | 老师后台 → 那位学生那一行 → **重设密码**，输入新的 4 位数字，告诉学生。 |
| 学生输错 5 次被锁住 | 等 10 分钟，或老师直接帮他重设密码（会立刻解锁）。 |
| 想停止新学生注册 | 老师后台 → **关闭注册**。已经注册的学生照样可以登入。 |
| 修改了 `Code.gs` | 要 **部署 → 管理部署 → 编辑（铅笔）→ 版本选「新版本」→ 部署**，网址不会变。 |
| 想看原始资料 | 直接打开 Google 表格的「学生 Students」分页。每位学生一行，M1–M9 栏显示星星、闯关最高分、游戏完成数和进度。密码只存加密后的数值，任何人都看不到原本的密码。 |

## 隐私

- 不收集邮箱、真实姓名或照片，只有班级代码、学生自己取的昵称和游戏进度。
- 资料只存在你自己的 Google 表格里。
- 密码用加盐 SHA-256 存储；登入错 5 次会锁住 10 分钟。
