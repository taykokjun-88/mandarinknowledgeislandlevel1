# 自定义背景音乐 Custom background music

把 mp3 放进这个文件夹，并把名字加进 `list.json`，那座岛就会播放你的音乐，代替程序合成的音乐。
Put an mp3 here and add its name to `list.json`; that island will play it instead of the built-in music.

文件名 File names: `ocean.mp3`（全景 overview）、`M1.mp3` … `M9.mp3`

`list.json` 例子 example: `["ocean","M1","M3"]`

请只使用你有权使用的音乐（例如自己录的，或标明可免费商用/教育使用的音乐），并保留作者与授权资讯。
Only use music you have the right to use, and keep the author and licence details.
